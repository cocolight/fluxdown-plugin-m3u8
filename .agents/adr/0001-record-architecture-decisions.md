# 采用 ADR 记录架构决策

- 状态：已接受
- 日期：2026-11-01
- 决策者：fluxdown-plugin-m3u8 维护者

## 背景

项目需要一个轻量、可追溯的方式记录重要架构决策，避免同一问题反复讨论，
也避免 AI 助手在不了解既有约束的情况下「想当然」地改动。

## 决策

在 `.agents/adr/` 下用 Markdown 记录架构决策，命名 `NNNN-kebab-title.md`；
「已接受」的记录只增不改，变更通过新增 ADR 表达取代关系。

## 后果

- 正面：决策可追溯；新成员与 AI 助手有据可依。
- 负面：需要维护成本；仅「重要 / 难以回退」的决策才写，小改动不必写。

## 备选方案

- 只写在 PR / 提交信息里：检索困难，易丢失。
- 使用外部 wiki：增加外部依赖，离线不可查。
