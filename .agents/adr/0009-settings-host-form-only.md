# 设置面收敛为宿主表单，删除自定义视图

> **本记录取代 [0008](0008-three-tab-settings-view.md)。** 0008 的「三页签视图」是同一目标的中间形态；
> 宿主对话框在「视图 + 表单」并存时自带一层页签（「插件设置 / 基础设置」），视图内再分三页就成了
> 嵌套菜单。以下是现行做法。同时解除 [0005](0005-allow-sdk-jsx-runtime.md) 的 JSX 运行时例外，
> 恢复 [0003](0003-sdk-type-only-import.md) 的「产物零 SDK 运行时」。

- 状态：已接受
- 日期：2026-11-02
- 决策者：fluxdown-plugin-m3u8 维护者
- 取代：[0008](0008-three-tab-settings-view.md)；解除 [0005](0005-allow-sdk-jsx-runtime.md)

## 背景

0008 落地后，设置页是两层页签：宿主的「插件设置 / 基础设置」之上又叠了视图的「基础 / 参数 / 去广告」。三个问题：

1. **嵌套菜单**。宿主只在「视图 + 表单」同时存在时画页签条（`plugin_settings.rs:537` 注释：
   「只有一个可用内容时不显示 tab 栏」），插件再分页就把取用路径拉到三层。
2. **同名歧义**。视图内层的「基础设置」与宿主顶层「基础设置」同名不同物。
3. **两套真相**。27 项在视图和宿主表单各出现一次，key 漂移要靠测试整段钉住。

SDK 的设置标准路径本来就是 `manifest.settings[]` → 宿主自动生成表单（官方 your-first-plugin.md：
「应用会自动为你的插件生成设置表单」）。

## 决策

1. **删除自定义视图**：`contributes.views`、`main` 入口、`src/entry/main.tsx` 一并去掉。对话框只剩
   宿主表单 —— 按「只有一个可用内容时不显示 tab 栏」，页签条整个消失，零页签。
2. **分门别类做进声明**（表单是平铺的，`SettingField` 仍无 group 字段）：
   - 11 个开关连续排最前。宿主把**连续的开关字段合并进同一张卡片**（`plugin_settings.rs` 的
     option_group 归并）—— 这就是「基础设置只留开关」在宿主表单里的形态。
   - 其余 16 项按主题聚簇，标题带「主题 · 项目」前缀（画质 / 音轨 / 命名 / 站点 / 网络 / 解析 /
     剧集 / 下载 / 去广告），同主题连续、去广告殿后。
   - 规则 JSON 的格式示例写进 `adRulesExtra` 的描述（替代预设按钮）。
3. **默认值维持推荐值（方案A）**，逐项锁定在 `tests/ui.mjs` 的 `DEFAULTS`，并由「manifest ↔
   `settings.ts` 兜底对账」双向钉死。
4. **红线 #3 随之收紧**：JSX 运行时的唯一例外消失，全部入口零 SDK 运行时。

## 后果

- 正面：零页签、单一设置面；声明即界面，视图与 manifest 的 key 漂移面整块消失；`dist` 少一个入口
  与 JSX 运行时（AGPL 面积收缩，`THIRD-PARTY.md` 对应条目移除）。
- 负面，三条：
  1. **去广告预设按钮与即时校验随视图移除**。模式选择（关闭 / 仅按标记 / 标记 + 推测）覆盖基本用法；
     自定义规则改为「字段描述带 JSON 示例 + `docs/settings.md`」。
  2. 平铺 27 项的分组只有「开关卡片 + 标题前缀」两种手段，没有真正的分区标题 —— 引擎不给
     group 字段，这已是在宿主表单内能做到的极限。
  3. `tests/ui.mjs` 从渲染测试（48 项）改为声明契约（18 项）：测「声明应该是什么样」，不再测交互。
- 门禁：ui 48 → 18 项（结构 4 / 前缀 2 / 默认值 3 / 字段合法性 5 / 产物形态 4）；contract 29 → 32 项
  （新增：manifest 无 `main`、无 `contributes.views`、dist 无 `main.js`）。
- 变异自检三处：① 把 `fixMuxFallback` 挪出开关段 → 4 项红；② `manifestMinItems` 默认 3→5 → 2 项红
  （含 settings.ts 对账项）；③ 「画质 · 档位」去掉主题前缀 → 1 项红。

## 备选方案

- **视图只留「去广告助手」（预设按钮 + 即时校验）**：宿主对话框仍是两个页签，且规则文本在视图与
  表单各有一个入口，「两套真相」原样回来。
- **清空 `manifest.settings` 全迁 `flux.storage`，视图内自组三页签**：能自绘分区标题，但设置读取
  全面异步化、老配置无法自动迁移（须两步发版），且偏离 SDK 的标准设置路径。
- **只重排声明、保留三页签视图**：嵌套菜单与同名歧义原样保留。
